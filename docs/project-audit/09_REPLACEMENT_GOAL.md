# 09. 대체 Goal 기록 — 2026-09-20

## Goal — ControlStudio 오프라인 PLC Agent의 실제 수정·완성 흐름 복구

### Outcome

합의된 Windows/LS XG5000/XG-SIM·모델 지원 프로필에서, 일반 사용자의 자연어 목표를 받은 ControlStudio가 기존 작업공간과 도구를 사용해 PLC 프로젝트를 조사·작성·실행·수정하고, 사람이 읽을 수 있는 native 작업본과 해당 revision의 검증 결과를 전달한다. Agent의 설계/도구/수정 판단을 기계별 정답 workflow로 대체하지 않는다.

완료할 사용자 여정은 다음 네 가지다.

1. **신규:** 대동인덱스 신규 요청으로 시작, 필요한 요구만 질문, 확정 조건 보존, 생성→native 적용→저장/재열기→합의 시나리오 완료.
2. **실패 후 수정:** 관측한 실패를 Agent가 조회·일반 편집으로 해결, 변경 source를 실제 적용·저장·readback, **그 source**로 재시험. 기존 성공 receipt의 재사용으로 통과 금지.
3. **후속/복구:** 기존 프로젝트 설명과 자연어 변경, 중단·재시작·후속 지시 처리. 원본 보존, 결과불명 중복 실행 없음, 요구/작업 내역 유지.
4. **일반화:** 제어 구조가 다른 합의 장비 사례 하나에서 동일 일반 도구 루프 사용. 인덱스 전용 수리 코드에 의존하지 않음.

### 명시적 비범위

물리 PLC 운전/쓰기, SSH·Session0·Task Scheduler 해결, 모든 vendor/모든 명령, 모든 OpenAI-compatible 모델의 동등 품질, 전면 CLI backend 추출, production 서명·설치 출시는 이 Goal의 자동 범위가 아니다. RB-20~24는 별도 결정/출시/선택 작업이며, 현 기능 인수의 미완료를 숨길 핑계로 사용하지 않는다.
