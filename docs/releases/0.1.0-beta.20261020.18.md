정확한 조합은 [동결 BOM18](../../../artifacts/product-release-20261011-native-sim/candidate-beta-18-assembled/portable/controlstudio.bom.json)과
[final18-pins](../../../artifacts/product-release-20261011-native-sim/maintenance18-candidate/final18-pins.json)을 따른다.
[Setup18-r149](../../../artifacts/product-release-20261011-native-sim/ControlStudio-Beta-Setup-20261020.18-r149.exe)의 SHA-256은
`cf9a8885e4084fe4aff99a00dfb97fada3c638af5d2eec461925767947240083`이다.

공개 사용자 진입점은 설치된 `ControlStudio Beta.exe --web`이다. Beta는 8766,
source development는 8767을 사용하며 기본 프로필도 분리된다. 기존 XG5000은 웹의
`열린 창 연결` → `이 프로젝트 연결`에서 현재 창·프로젝트 정체성을 검증해 연결한다.
Development 프로필을 환경 override로 제자리 재사용한 절차는 내부 인수 범위이며,
일반 Beta 사용의 필수 gate나 기본 프로필 동작으로 확대하지 않는다.

[op04 결과](../../../artifacts/product-release-20261011-native-sim/maintenance18-candidate/maintenance18-operation04-result.json)는
실제 Setup 실행, 설치 파일 after8 exact, fixture 사용자 파일 3개·unknown 잔여물 보존,
공개 Web bootstrap·재연결 PASS를 기록한다. 이는 전체 사용자 프로필이나 12GB DB의
전후 해시 검증이 아니며, 회로·SIM 기능 인수 완료를 뜻하지 않는다.
이전 기능 인수의 범위와 현재 진행 상태는 [통합 원장](../../../artifacts/product-release-20261011-native-sim/reviewed-product-observation-and-packaging-109-112-applied.json)·[HANDOFF](../../../HANDOFF.md)를 따른다.

[동결 BOM17](../../../artifacts/product-release-20261011-native-sim/candidate-beta-17-assembled/portable/controlstudio.bom.json)과 BOM18의
Platform·Agent SHA가 같아 17→18 조합에는 새 Host 구현·schema 변경이 없다.
이는 별도 schema migration 또는 backup/restore 실패 주입 시험의 합격 근거가 아니며,
그 시험은 미완료다. 업데이트 전 공식 UI로 정상 종료하고,
검증된 전체 BOM 조합의 rollback·별도 사용자 DB·hash-owned 정리와 unknown 보존은
[배포·업데이트 정책](../refactor/PRODUCT_DISTRIBUTION_AND_VERSIONING.md)을 따른다.

EXE09 실제 작은 context 지속 실행, EXE10 실제 실패 후 회로 수정,
